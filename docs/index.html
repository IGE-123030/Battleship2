Battleship Game Player

Java project developed at ISCTE-IUL

📌 Project Overview

Battleship Game Player is a Java implementation of the classic Battleship game, developed as an academic project. It includes game logic, AI opponent, and a graphical interface.

⚙️ Main Features

  • Full Battleship game engine (rules, ships, moves)
  • AI player logic
  • JavaFX graphical user interface (BoardGUI)
  • Fleet and ship management system
  • Move tracking and game state system
  • Database logging (DatabaseManager)

🧩 Project Structure

  • Game / IGame – core logic
  • Fleet / Ship – ship system
  • Position / Move – gameplay tracking
  • BoardGUI – graphical interface
  • Tasks – game flow / input handling

🛠️ Technologies Used

  • Java 21
  • Maven
  • JavaFX
  • JUnit 5
  • Log4j
  • Jackson

🚀 How to Run


mvn clean package
java -jar target/BattleshipGamePlayer-2.0.jar
